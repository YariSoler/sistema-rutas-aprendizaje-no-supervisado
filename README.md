# Sistema Inteligente de Rutas de Transporte

## 1. Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema inteligente en Python capaz de encontrar una ruta entre dos estaciones de un sistema de transporte masivo.

El sistema utiliza una base de conocimiento representada mediante estaciones y conexiones, reglas lógicas para validar la información proporcionada por el usuario y el algoritmo de búsqueda heurística A* para encontrar una ruta de menor costo dentro del grafo definido.

El modelo utilizado corresponde a una representación académica simplificada de estaciones y conexiones del sistema de transporte.

---

## 2. Objetivo

Desarrollar un sistema inteligente que permita encontrar una ruta entre una estación de origen y una estación de destino utilizando representación del conocimiento, reglas lógicas y búsqueda heurística.

## 5. Instrucciones para ejecutar el proyecto

Paso 1. Preparar el entorno

Instala Python 3 y Visual Studio Code en tu computador.

Paso 2. Abrir el proyecto

Abre Visual Studio Code y selecciona la carpeta donde está guardado el proyecto. En las capturas del documento aparece como sistema_rutas_ia.

Paso 3. Abrir la terminal

En Visual Studio Code, selecciona:

Terminal → Nueva terminal.

Paso 4. Ejecutar el programa

Escribe el siguiente comando:

python main.py

En Windows, si el comando anterior no funciona, puedes intentar:

py main.py

Paso 5. Seleccionar las estaciones

El programa mostrará las estaciones disponibles y solicitará:

Estación de origen.

Estación de destino
